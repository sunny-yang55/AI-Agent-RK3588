小安 · RK3588 智能语音助手 用户使用手册
版本：v1.3.14-voice-ui-freeze

一、主要功能

1. 普通对话无需唤醒词，直接讲话即可。
2. 支持连续多轮对话，例如先询问“介绍一下芜湖”，再问“它有哪些景点”。
3. 语音播报过程中说“小安停止”，可以停止当前播报。
4. 说“再见”“退出”或“拜拜”，可以退出语音助手。
5. 默认使用在线自然语音；网络语音失败时可自动切换离线语音。

二、启动方法

打开终端，执行：

cd /home/ztl/AI-Agent-RK3588
./run_rk3588.sh

如果提示权限不足，执行：

chmod +x run_rk3588.sh
./run_rk3588.sh

三、使用方法

看到“● 正在聆听…”后直接讲话。

示例：

介绍一下安徽芜湖。
它有哪些景点？
介绍一下安徽工程大学。
小安停止。
好的，再见。

四、界面状态说明

● 正在聆听：等待用户讲话。
◌ 正在思考：正在生成回答。
▶ 正在播报：正在播放语音。
✓ 回答完成：本轮回答和播报结束。
■ 已停止当前播报：用户已成功打断。
✓ 语音助手已退出：程序已正常结束。

五、常见问题

1. 没有听到声音：检查扬声器音量和网络，然后重新启动。
2. 没有识别出讲话：靠近麦克风，减少环境噪声，并在出现“正在聆听”后讲话。
3. 无法停止播报：清楚说出“小安停止”，不能只说“停止”。
4. 提示找不到虚拟环境：联系维护人员检查启动配置，不要自行重装系统。
5. 程序异常退出：把 logs/voice-debug.log 提供给维护人员。

六、注意事项

语音助手的回答由大模型生成，涉及人数、排名、学校专业、公司技术等时效信息时，应以官方网站最新信息为准。
